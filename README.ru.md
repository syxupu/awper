# AWPER

[English](README.md) · [Русский](README.ru.md) · [中文](README.zh-CN.md)

AWPER — это плагин для тренировки AWP-стрейфа (горизонтального пика) для **выделенных серверов Counter-Strike 2**. Администраторы могут записывать позиции игрока, точки старта и финиша бота прямо на официальных картах и сохранять их как переиспользуемые тренировочные маршруты. Игрок загружает маршрут, проверяет обзор через фиксированную камеру и многократно отрабатывает боковое перемещение бота между двумя точками.

Текущая версия: **1.1.0**

> Это сообщественный плагин, не связанный с Valve и не одобренный ими. Это не карта Мастерской, он должен работать на выделенном сервере CS2 с установленным CounterStrikeSharp.

## Основные возможности

- Создание, проверка, сохранение и загрузка тренировочных маршрутов на официальных картах.
- Отдельный режим редактирования через `!edit <имя>`, чтобы обычные игроки случайно не изменили точки.
- Запись `EditAnchor`, `PlayerAnchor`, `BotStart`, `BotEnd` и опционального `BotJiggle`.
- Одиночный клик Mouse4 переключает предпросмотр с фиксированной камерой; камера находится в `PlayerAnchor`, а модель игрока сохраняет направление взгляда на момент нажатия клавиши.
- Бот воспроизводит движение через реальный Pawn и нативный ввод CS2-Bot-Controller, без телепортации по тикам.
- Бот разгоняется с места в соответствии с текущими `sv_accelerate`, `sv_friction`, `sv_stopspeed` и тиком сервера.
- Запуск одного раунда с указанной скоростью без изменения самого маршрута: `!start_speed <1-215>`.
- Копирование маршрута с изменением только имени и скорости: `!copy <исходный> <новый> <1-215>`.
- F5 открывает нативное центральное меню CounterStrikeSharp; команды чата всегда остаются резервным способом ввода.
- Перед сохранением, загрузкой и запуском выполняются проверки свободного пространства, земли, пролёта пути и прямой видимости; при неудачной проверке запуск отклоняется.
- Идемпотентная очистка ботов и выпавшего оружия после каждого раунда, поддержка последовательных раундов.

## Логика работы

```text
Администратор создаёт маршрут
  !edit <имя>
        │
        ├─ EditAnchor       Точка входа в редактирование
        ├─ PlayerAnchor     Позиция тренировки / камера
        ├─ BotStart         Точка старта бота
        ├─ BotEnd           Точка финиша бота
        └─ BotJiggle        Опциональная точка дёргания
        │
        ▼
  Живая проверка Ray-Trace ──ошибка──> Отказ от сохранения с объяснением
        │ успешно
        ▼
  Сохранение как profiles/<карта>/<имя>.json

Игрок тренируется
  !load <имя> → предпросмотр Mouse4 → Mouse5 / !start
        │
        ▼
  Обратный отсчёт → случайная задержка → спавн бота → воспроизведение нативным вводом
        │
        ├─ Бот погибает
        ├─ Достигает финиша
        ├─ Застревает / тайм-аут
        └─ Игрок прерывает
        │
        ▼
  Очистка бота и оружия → восстановление игрока → следующий раунд
```

Полные параметры команд и порядок редактирования см. в [command.md](command.md).

## Требования

- Выделенный сервер CS2.
- [Metamod:Source](https://www.sourcemm.net/).
- [CounterStrikeSharp](https://github.com/roflmuffin/CounterStrikeSharp) API 1.0.373 или выше.
- [CS2-Bot-Controller](https://github.com/XBribo/CS2-Bot-Controller), текущий ABI 19.
- [FUNPLAY Ray-Trace](https://github.com/FUNPLAY-pro-CS2/Ray-Trace), включая native, RayTraceImpl и общий RayTraceApi.
- Целевая версия CS2 должна поддерживать `cs_player_camera`.

Релизный пакет не перераспространяет бинарники перечисленных зависимостей — установите каждую по инструкциям соответствующих проектов.

## Установка

1. Скачайте `AwperTrainer-1.1.0.zip` из GitHub Releases и распакуйте.
2. Поместите рантайм-файлы на сервер:

```text
game/csgo/addons/counterstrikesharp/plugins/AwperTrainer/
├─ AwperTrainer.dll
├─ AwperTrainer.Core.dll
├─ AwperTrainer.deps.json
└─ AwperTrainer.runtimeconfig.json
```

3. Скопируйте ресурсы-мосты из релизного пакета в соответствующие каталоги сервера:

```text
resources/awper_camera.vjs_c  -> game/csgo/scripts/awper/awper_camera.vjs_c
resources/awper_hud.vjs_c     -> game/csgo/scripts/awper/awper_hud.vjs_c
resources/awper_hud.vxml_c    -> game/csgo/panorama/layout/custom_game/awper_hud.vxml_c
resources/awper_hud.vcss_c    -> game/csgo/panorama/styles/custom_game/awper_hud.vcss_c
```

4. Убедитесь, что плагины BotController и RayTrace, общий API и нативные модули установлены, затем перезапустите сервер.
5. Зайдите на сервер и введите `!status`, чтобы убедиться, что BotController, RayTrace и камера доступны.

Конфигурация плагина находится здесь:

```text
game/csgo/addons/counterstrikesharp/configs/plugins/AwperTrainer/AwperTrainer.json
```

Тренировочные маршруты сохраняются по картам:

```text
game/csgo/addons/counterstrikesharp/configs/plugins/AwperTrainer/profiles/<карта>/<имя>.json
```

## Клавиши игрока

Можно задать напрямую в клиентской консоли:

```cfg
bind "F5" "css_ui"
bind "MOUSE4" "css_preview_toggle"
bind "MOUSE5" "css_start"
```

Либо поместите `awper_bindings.cfg` из релизного пакета в клиентский `game/csgo/cfg/` и выполните:

```text
exec awper_bindings
```

F5 использует центральное меню CounterStrikeSharp, предоставляемое сервером. Даже без привязки F5 меню можно открыть командой `!ui` в чате.

## Быстрый старт

Загрузите существующий маршрут:

```text
!list
!load mirage_awp_1
```

После загрузки сначала нажмите Mouse4, чтобы проверить камеру, затем Mouse5, чтобы начать тренировку. Можно использовать и команды чата:

```text
!preview_toggle
!start
```

Запустить только этот раунд на 180 units/s, не меняя сохранённый маршрут:

```text
!start_speed 180
```

## Создание маршрута

```text
!edit mirage_awp_1
!set_edit_anchor
!set_player_anchor
!set_bot_start
!set_bot_end
!set_bot_facing
!mode 1
!speed 215
!validate
!save
```

Рекомендуемый порядок:

1. Войдите в режим редактирования в безопасном месте и запишите `EditAnchor`.
2. Подойдите к реальной тренировочной позиции и запишите `PlayerAnchor`.
3. Подойдите туда, где должен появляться бот, и запишите `BotStart`.
4. Подойдите туда, где заканчивается стрейф, и запишите `BotEnd`.
5. При необходимости запишите направление взгляда бота и точку дёргания.
6. Предпросмотрите через Mouse4, затем выполните `!validate` и `!save`.

Имена маршрутов могут содержать только английские буквы, цифры, знаки подчёркивания и дефисы, длиной от 1 до 64 символов.

## Основные команды

| Команда | Назначение |
|---|---|
| `!help` | Показать краткую справку |
| `!ui` | Открыть или закрыть центральное меню F5 |
| `!status` | Показать состояние плагина, зависимостей и текущей тренировки |
| `!list` | Список маршрутов текущей карты |
| `!load <имя>` | Загрузить маршрут |
| `!start` | Начать со скоростью, сохранённой в маршруте |
| `!start_speed <1-215>` | Переопределить скорость бота только на этот раунд |
| `!copy <исходный> <новый> <1-215>` | Скопировать маршрут, изменив только имя и скорость |
| `!abort` | Прервать тренировку или редактирование и восстановить игрока |
| `!maps` | Список карт, на которые разрешено переключиться |

В любой команде чата `!` можно заменить на `/`; консольная форма добавляет к имени префикс `css_`, например `!start` соответствует `css_start`. Команды AWPER больше не используют старый префикс `awper_`.

## Модель движения бота

Скорость в конфигурации — это верхний предел целевой наземной скорости. Каждый тик плагин сначала применяет трение о землю, затем ускоряется вдоль направления пути по модели наземного ускорения Source, поэтому бот не достигает 215 units/s на первом же кадре. Короткий путь может закончиться раньше достижения целевой скорости — это нормально.

Плагин не имитирует движение через телепортацию по тикам; если интерфейс BotController или нативные возможности недоступны, тренировка отказывается запускаться.

Требуются PowerShell 7 и `.NET SDK 10.0.201`:

pwsh.exe -NoLogo -NoProfile -NonInteractive -File .\build.ps1

## Известные ограничения

- Репозиторий содержит только логику плагина; он не поставляет контент официальных карт и готовые маршруты для семи карт.
- Каждая карта и каждая тренировочная позиция по-прежнему требуют записи и проверки маршрута администратором.
- После обновления CS2, CounterStrikeSharp, BotController или RayTrace следует повторно провести проверку на сервере.
- Текущая архитектура запускает одну тренировочную сессию за раз и подходит для личных серверов или серверов с поочерёдной тренировкой.
